## H1 · Backdrop（推荐工程默认）

### 问题

真玻璃要采背后像素；全场景实时截屏易翻车。

### 推荐默认（务实，写入产品承诺）

| 规则 | 内容 |
| --- | --- |
| 默认输入 | **宿主提交缓存纹理**（策略 B）：Kuikly Bridge 在适当时机把 Holm **下方局部**绘入纹理交给 Holm；或第一期用 **策略 A 程序化/静态图** |
| 分辨率 | **半分辨率**采样 + 双线性放大（默认可关） |
| 静态冻结 | 下方 UI 无变化时 **冻结** backdrop，停止每帧重采 |
| **明确不支持** | **列表滚动中的实时真折射**；动画剧烈背景下可自动降为普通模糊/策略 A |
| 禁止吹嘘 | 文档与 Demo 不得写「全场景实时完美采样」 |

### 策略枚举（须显式选择）

| 策略 | 含义 |
| --- | --- |
| A | 程序化/静态图（最稳；M1 可默认） |
| B | 宿主提交纹理（推荐真霜化方向） |
| C | 运行时全自动截层（高风险；默认不做） |

Stage 0 须写：第一期 A 还是 B；是否接受「滚动不真采」。

### 证据

Kuikly Blur target refs；Haze/Imla；实时 blur 成本文。

## H2 · 滚动与合成

1. Holm 放 **非滚动英雄区** 或固定浮层。  
2. 不承诺 List 内实时 + 真 backdrop。  
3. M1：下方 Scroller 狂滑录屏；不通过则保持 A + 固定岛。

---

## H3 · 手势

| 场景 | 策略 |
| --- | --- |
| 纯展示 | 可穿透或少消费 |
| 3D 旋转 | 单指消费；与外层滑动互斥写清 |
| 按钮 | **Kuikly 兄弟节点**叠在岛上，不进 GPU 树 |

## H4 · 生命周期与 List

1. detach → `holm_destroy`（或 Lite 等价释放）。  
2. **默认禁止** List 内实时 Holm。  
3. 只要外观：预烘焙 / `playing=false` 静态纹理。  
4. M3：进出 50 次压测。
