# Phase M0 · 通面（HolmSurface + Runtime）

> **前置门禁**：`phases/Stage0.md` 结论必须为 **Standard(B)**。选 Lite(A) 禁止本阶段全量 Runtime；应去交业务特效。  
> 即使本阶段做通面，也须尽快接上至少 1 个官方特效（效果优先，忌空引擎）。  
> **目标**：Kuikly 页挂 Holm 岛，共享 Runtime/RHI 稳定出帧。  
> **不做**：折射、glTF、完整黄金图 CI、WebView 方案。  
> **前置阅读**：`../00`、`../07`、`../01`–`../03`

## DoD

1. 至少 **Android + iOS**（或 Android + Web）Demo 可见清屏或三角。  
2. `onReady` 回报 backend。  
3. resize、退进页、destroy 不崩。  
4. 尖刺报告（包体、鸿蒙、O1）写入本文末或 `../00`。  
5. **禁止**系统 Liquid Glass / WebView+Three 充数。
